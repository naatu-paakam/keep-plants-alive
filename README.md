# Keep Your Plants Alive

**Status:** In development — plant health diagnosis feature built  
**Type:** E-commerce storefront + AI plant diagnosis  
**Stack:** Vite + React + TypeScript + Tailwind + Netlify Functions + Claude API  
**Port:** 5180 (Vite dev) / 8888 (netlify dev)

## What This Is

A curated online store selling practical tools that solve the most common reasons plants die.
Core feature: upload a plant photo → Claude vision API diagnoses the health issue → recommends the right tool from the store.

## Local Dev

> Use `netlify dev`, not `npm run dev`. The plant diagnosis feature calls a Netlify Function
> (`/.netlify/functions/claude-proxy`) which only runs under `netlify dev`.

### First-time setup

```bash
# 1. Install dependencies
npm install

# 2. Create .env.local with your Anthropic API key (gitignored — never commit)
echo "ANTHROPIC_API_KEY=sk-ant-your-key-here" > .env.local
#    Get the key from: https://console.anthropic.com → API keys

# 3. Start the dev server
npm run netlify:dev
# Opens at http://localhost:8888
```

### If you only need the UI (no diagnosis feature)

```bash
npm run dev
# Opens at http://localhost:5180
# The /diagnose page will load but Claude API calls will fail (no function runtime)
```

## Security Model

| Key | Where it lives | Who sees it |
|---|---|---|
| `ANTHROPIC_API_KEY` | `.env.local` locally, Netlify dashboard in prod | Server only (Netlify Function) |
| Never in browser bundle | `VITE_` prefix intentionally NOT used | — |

The `netlify/functions/claude-proxy.js` function is a **generic pass-through proxy** — it accepts any Claude Messages API body from the browser, adds the key from `process.env.ANTHROPIC_API_KEY`, and returns the response. Copy it into any NaatuPaakam project to get the same pattern.
